# UX17 — same filename on all disks (any recorded size)

Use a **selected, current loaded file** on Windows Win32 or macOS SwiftUI. Windows View → Find same filename / Ctrl+Shift+N; macOS native locator → Find same filename (any size) / Command-Shift-N. The app switches to **global** `name_exact:"quoted file name"` search without inspecting USB media. Multiple recorded sizes or multiple catalog disks appear as separate result rows; Back returns to the previous search, page and scope. The editable search field supports refinement.

The bound query is case-insensitive via catalog name normalization, literal for punctuation/quotes/wildcards, and capped at 4096 UTF-8 bytes. Null/empty or oversized names refuse the transition. Async page invalidation prevents selecting an old file while a new page is loading. The separate **Find copies** compares normalized name **and** byte size; this UX17 mode ignores recorded size. Neither proves content equality, hardware presence, successful retrieval, safe deletion, codec nor movie-title identity. Source-linked CTF operations recheck original generation SHA per page and remain read-only; private pairing/shelf tags/annotations remain in owner-side databases.
