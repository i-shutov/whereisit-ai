# WhereIsIt AI — состояние на 2026-10-28

## Назначение

Нативный каталог офлайн-дисков Windows/macOS; Windows Win32, macOS SwiftUI/AppKit, общее ядро Rust + SQLite. CTF — формат импорта/экспорта. В повседневной работе данные хранятся в собственной базе с поисковыми индексами. По умолчанию сканируются только метаданные, без содержимого файлов и плагинов.

## Реализовано и проверено

| Возможность | Статус / доказательство |
|---|---|
| Разбор CTF | Поддержан исследованный несжатый Catalog 3.00; полный корпус 44 диска, 3 046 027 записей. |
| Импорт в SQLite | Полный импорт; `PRAGMA quick_check=ok`; проверены внешние ключи. |
| Обратный экспорт CTF | Для неизменённого каталога побайтовое совпадение: 144 766 574 байта, SHA-256 `REDACTED_SHA256`. |
| Поиск | Boolean AND/OR/NOT, скобки, размеры, расширения, имена/пути, маски, описания, теги, категории; тесты и замеры на реальной БД. |
| Дубликаты | Кандидаты по имени/размеру; фильтры movies/music; кэш групп. Это **не** доказательство побайтового равенства файлов. |
| Выгрузка | CSV/Parquet для веток и выборок, включая группы дубликатов; независимо проверены строки и типы. |
| Windows | EXE и CLI собраны; GUI проверен под Wine, CLI проверен на 3 млн записей. Не заменяет испытание на настоящей Windows. |
| macOS | Клиент и скрипт сборки подготовлены; сборка/исполнение на macOS пока **не** проверены. |
| Rust QA | 26 release-тестов; fmt и clippy `-D warnings` — по отчёту предыдущего выпуска. |

## Производительность (Linux, прогретый кэш, не SLA)

- Первая страница всех записей: 7,4 мс (p50).
- Подстрока имени: 6,4–13,2 мс (p50 по двум сценариям).
- Составные фильтры видео/музыки: 57,9–58,8 мс (p50).
- Наследуемая категория на ветке в 374 259 записей: 1,13 с (медиана).
- Поздние прогоны группировки фильмов/музыки: 0,31/0,35 с для первой операции. Первое построение групп **всех** файлов: 22,9–28,7 с по разным запускам; страницы кэша ~5–8 мс.
- Компактная выпускаемая SQLite: 2 161 020 928 байт; исходный CTF — 144 766 574 байта. Существенное увеличение размера — известный технический долг.

## Не завершено / блокеры приёмки

1. Испытать GUI на настоящей Windows 10/11 и проверить DPI, выбор устройств, импорт/поиск/экспорт.
2. Собрать и проверить `.app` на macOS (Apple Silicon; далее Intel при необходимости).
3. Проверить *новые и отредактированные* CTF в исходной WhereIsIt, отдельно от побайтового roundtrip неизменённого файла.
4. Полноценно отобразить категории/группы исходного CTF в собственную схему и обратно; текущий экспорт не допускает тихой потери новых категорий/тегов.
5. Уменьшить БД, ускорить большие категории и потоковый CTF импорт, улучшить отмену долгих операций.
