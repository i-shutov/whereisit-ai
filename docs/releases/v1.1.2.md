# WhereIsIt AI 1.1.2 — Windows x64 (unsigned)

This candidate reduces memory use while opening large CTF catalogs through a
typed, read-only metadata view. The full-fidelity parser remains in use for
imports and exports. Exact-artifact installed GUI validation and stable
publication are separate final checks; this note does not claim they have
passed. Published 1.1.1 tags and assets remain immutable.

## Changes

- Parse the preview directly into compact metadata entries instead of building
  a full catalog and converting it. Structural, encoding, range and aggregate
  budget validation remain shared with the full parser.
- Keep opaque bytes in the full import/export representation. Metadata entries
  cannot be passed to the CTF writer; preview does not change source catalogs.
- Preserve source binding and existing query and cancellation behavior.

## Measurements and evidence

On a 44-volume, 3,046,133-record catalog, three fresh-process service runs
observed peak working sets of about 549 MiB (prior baseline maximum: 862 MiB),
peak commit of about 554 MiB (baseline: 1,081 MiB), and retained private memory
after open of about 467 MiB (baseline: 733 MiB). Opening through first search
took 0.891–0.970 seconds in these runs. These are service-process measurements,
not GUI timings or guarantees; cache and Windows paging were uncontrolled.

Full and metadata parses were compared across all entries, the full writer
roundtrip was byte-identical, and source bytes remained unchanged. One
30-sample size/count series measured p95 186.376 ms, above the 150 ms target;
three paired fresh-process repeats measured candidate p95s of 85.090,
86.080 and 81.795 ms, with no regression versus their paired baselines. This
does not establish an all-query SLO or hardware latency guarantee. See the
[sanitized QA report](../qa/CTF_OPEN_MEMORY_20261127.md) for methodology,
coverage and limitations.

Windows x64 is the product scope; the installer is unsigned. macOS/Linux
product releases are deferred while portable compile/tests continue. Windows
10 testing is owner-confirmed historical coverage, not an exact 1.1.2 PASS.
Original CTFs remain read-only and full-fidelity import/export is retained. No
personal catalog data or private measurement artifacts are included here.
