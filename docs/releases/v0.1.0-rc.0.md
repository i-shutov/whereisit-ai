## Included features

- Native Rust Win32 GUI; SwiftUI/AppKit GUI for two Mac architectures.
- Offline catalog and search, CTF import/export for the observed uncompressed WhereIsIt Catalog 3.00 variant.
- SQLite metadata database; Boolean AND/OR/NOT search, tree, hierarchical categories.
- Candidate duplicate grouping by name/size without reading media files; CSV/Parquet scopes and CTF interchange.
- Windows Inno Setup per-user installer and Mac pkg/dmg packaging scripts.

## Explicit gaps

- Clean installation, launch, uninstall and import/export with real user catalogs **not yet validated natively** on any target desktop OS.
- Original WhereIsIt acceptance of newly created or modified CTF **not yet verified**.
- The Hot/Cold migration experiment in PR #9, native sparse CTF change in PR #11 and release workflow in PR #10 are **not** part of this RC code snapshot unless present in the exact source SHA.
- The user SQLite dataset and source CTF were excluded from build artefacts.
- Authenticode, Apple Developer ID signatures and notarization are **not** present. OS security prompts may block execution.
- Full installer release / automatic upgrade is gated on end-to-end acceptance.

## Next release criteria

1. Finalize reviewed, all-OS green PRs in milestone M2 and compatibility M1.
2. Test on Windows 10/11 x64 and macOS Apple Silicon/Intel with verified database backup; test install/uninstall and CTF interchange.
3. Run controlled full 3M-row hot/cold benchmark; verify CTF SHA-256 roundtrip.
4. Publish a new git tag + prerelease via workflow with SHA256SUMS and provenance; sign/notarize only after trusted signing credentials are provided securely.
