# WhereIsIt AI 1.0.0-rc.4

RC4 is an unsigned prerelease of the native Rust/egui desktop application.

## Changes since RC3

- Import CTF catalogs in egui, inspect imported metadata, and export supported edits to a separate CTF copy. The original catalog stays read-only and unsupported structures are reported.
- Review physical device identity before pairing a catalog volume and explicitly choose when to rescan. Review copy candidates offline using catalog metadata; a name/size match does not establish content equality or a backup.
- Export complete search results and candidate sets as CSV, Parquet, or JSON, including results beyond the visible page.
- Reject malformed CTF sections with unaccounted data or invalid ranges. Existing catalogs open with a fast schema check and offer an explicit integrity check.
- Add dedicated Windows x64 and macOS ARM64 and Intel egui product packaging. The egui and legacy native installations have separate identities.

## Acceptance

Stable readiness remains false. Outstanding gates include exact RC4 package acceptance, RC3-to-RC4 upgrade and rollback verification, full desktop parity, independent physical GUI, DPI, accessibility and USB testing, Windows Authenticode signing, and macOS Developer ID signing and notarization. See the [release acceptance manifest](../../release/ACCEPTANCE.json).
