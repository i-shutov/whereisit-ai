# WhereIsIt AI 1.1.0-rc.1 — Windows x64 installer candidate

This unsigned candidate integrates PR58 tabs/workspaces (#87), archive slices and sunburst (#88), and the metadata-only local folder analyzer (#89). It is prepared for installed Windows QA and an in-place upgrade from the published 1.0.0 product. It is not a stable publication.

Workspaces retain their context. Catalog analysis uses read-only SQLite queries with bounded output and cancellation. Local analysis requires an explicit folder, reads filesystem metadata, skips links/reparse points and shows access errors. Name/size candidates do not prove content equality or a backup. Review CSV creates a new file; file deletion and cleanup scripts are absent. USB pairing and bound-media rescan remain disabled.

The product uses Rust/egui; the PR58 React prototype is a design reference and is not packaged. macOS/Linux product releases are deferred; useful cross-platform builds/tests continue. Windows 10 coverage remains owner-confirmed historical coverage, with no new physical 1.1 result asserted.

The 1.0.0 tag/assets and historical acceptance are immutable. This candidate uses separate acceptance with stable_ready=false and automatic candidate publication disabled. GUI/upgrade evidence must identify the exact main commit, installer and installed binaries, and distinguish synthetic data from historical private-catalog evidence. No user catalogs or proprietary license files are included.
