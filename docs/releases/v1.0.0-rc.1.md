# WhereIsIt AI 1.0.0-rc.1

**Release candidate, not stable 1.0.** Windows packages are unsigned; macOS apps are ad-hoc signed, not Developer ID notarized. This label is intentional: CI and synthetic fixtures do not establish acceptance of the private 3,046,027-entry user catalog or original WhereIsIt interoperability.

## Implemented in this candidate

- Native Windows Win32 and macOS SwiftUI/AppKit clients sharing the Rust engine; no Python, web runtime or database server required for end users.
- Fresh catalogs use schema v3: indexed `entries_core` and sparse `entry_payload`. Empty descriptions/tags do not allocate payload rows. The concatenated search document is computed instead of stored once per file.
- Hot queries filter the core before hydrating the bounded result page. Name/path/extension/size/category predicates, AND/OR/NOT, annotations, offline metadata duplicate candidates and CSV/Parquet scopes remain available.
- Verified copy-only compaction from catalog schemas 1, 2 or 3. Existing source databases are not upgraded on open. The source is attached read-only; a new output is published only after value parity, foreign keys, SQLite and FTS integrity checks. Existing files and source SQLite sidecars cannot be overwritten.
- Original CTF records are retained as dense raw provenance, not incorrectly treated as sparse extensions. The observed uncompressed Catalog 3.00 reader/writer and explicit refusal of lossy unsupported exports are retained.
- Native CLI commands: `validate <catalog>` and `compact <source> <new-copy>` in addition to JSON request/serve. CLI version, app metadata and installer version are checked against `VERSION`.
- Windows per-user Setup EXE and macOS ARM64/Intel PKG + DMG. Package hashes and source provenance accompany downloads. Windows install/uninstall and Mac package/install/CLI checks are required by the publication workflow.

## Safe migration

Back up the old catalog first. In the GUI choose **Catalog → Create compact copy…** on Windows, or **Compact copy…** on macOS. Use a **new** destination filename. The original remains selected and unchanged; open the verified copy explicitly afterward.

Windows CLI example (from the installation directory):

```powershell
.\whereisit-ai-cli.exe validate 'C:\Catalogs\old.atlas.sqlite'
.\whereisit-ai-cli.exe compact 'C:\Catalogs\old.atlas.sqlite' 'C:\Catalogs\compact.atlas.sqlite'
```

macOS CLI example:

```sh
'/Applications/WhereIsIt AI.app/Contents/MacOS/whereisit-ai-cli' compact \
  "$HOME/Catalogs/old.atlas.sqlite" "$HOME/Catalogs/compact.atlas.sqlite"
```

Do not use an old v0.1 binary to open a new schema-v3 file. Keep the original v1 file for rollback. Compaction can take time and requires free space for the new database and its transaction journal; it does not replace the source or run automatically.

## Still open before stable 1.0

- Full migration, query parity, performance measurements and CTF SHA-256 roundtrip on the user's actual 44-disk catalog. Synthetic benchmarks are explicitly labelled and do not replace this check.
- Original WhereIsIt opening newly generated and modified CTF files. Categories/groups and other unsupported legacy semantics must not be claimed implemented merely because unknown bytes are preserved.
- Full interactive GUI/DPI/accessibility checks on Windows 10/11 and supported macOS versions, plus upgrade scenarios and cancellation/progress for every long operation.
- Windows Authenticode signing and Apple Developer ID signing/notarization with securely configured credentials. No signatures or notarization are claimed by unsigned candidates.
- A measured alternative engine comparison (DuckDB/Polars) is not completed; the delivered engine remains SQLite. Full paths are still stored once, and descriptions share the compatibility trigram index; further physical-index changes require benchmarks.

**No private catalog, media listing, original proprietary program or license key is bundled.** Only hashes, synthetic test results and source/build provenance may be published. Stable-release acceptance remains separate from making this candidate installable.
