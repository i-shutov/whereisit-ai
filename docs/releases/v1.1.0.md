# WhereIsIt AI 1.1.0 — Windows x64 (unsigned)

Windows x64 release. See [stable acceptance](https://github.com/i-shutov/whereisit-ai/blob/v1.1.0/docs/qa/WINDOWS_1_1_STABLE_ACCEPTANCE_20261123.md) for measured results, exact tested artifacts and limitations; published provenance identifies the final source and CI run.

## What's included

- PR58 workspaces, archive slices and sunburst in the native Rust/egui application.
- Metadata-only local folder analysis with progress, cancellation, access-error reporting, skipped links, metadata candidate review, saved growth baselines and new-file review CSV export.
- Bounded catalog analytics with complete totals and explicit truncation/remainder; branch navigation remains available.
- Full supported CTF import/export and CSV/Parquet exports.

Local analysis reads filesystem metadata only. A matching name and size indicate a candidate, not byte equality or a backup. The app does not delete files or create executable cleanup scripts. USB pairing and bound-media rescan are disabled; ordinary metadata scanning remains supported.

## Validation recorded for this build

The exact main build was installed and exercised in a Windows 11 Administrator RDP session, including an upgrade from the published 1.0.0 installation and restart. Two generated external SQLite catalogs and a separate SQLite user-store remained byte-identical; notes, categories, preferences and 60-disk context remained available. The full catalog map used the fixed 128-node request, showed correct full totals and truncation details, and passed cancellation/retry interaction. Search six-class × 30-warm-sample testing passed the 150 ms p95 target; full-catalog CSV/Parquet parity passed across all 15 fields and all rows.

Original WhereIsIt 2014.0.0.220 opened the full modified CTF export; the Unicode Rust note was visible and a changed Unicode note was saved to a new CTF. The vendor-saved CTF imported successfully into native 1.1; all 3,046,133 entry rows and ten metadata fields matched except the single intended Unicode-description edit, and all semantic volume metadata matched. See the acceptance record for exact artifact identity, measurements, scope and limitations.

## Platform and data notes

Windows x64 is the product scope for this release. The installer is unsigned and has no Authenticode signature. macOS/Linux product releases are deferred; portable compile/tests continue. Windows 10 testing is owner-confirmed historical coverage, not a new exact-1.1 physical result.

Original user catalogs are read-only. CTF edits and exports use separate copies and new output names. No personal catalogs, source digests, raw rows, private paths, screenshots or proprietary license files are part of this release note or product package. The published v1.0.0 tag and assets remain unchanged.
