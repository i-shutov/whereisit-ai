# WhereIsIt AI 1.1.0 — Windows x64 (unsigned)

Windows 1.1 adds the PR58 workspaces, archive slices and sunburst, and the explicit metadata-only local folder analyzer. The native product remains Rust/egui with no web runtime.

Search, media, slices, volume map and local-PC workspaces keep their context when switching. Catalog analysis reports recorded logical bytes, not physical occupancy. Bounded trees explicitly disclose omitted nodes. Local folder analysis supports progress/cancellation, skipped links and access errors, metadata candidate review, a saved growth baseline, and a new-file review CSV export.

The analyzer reads filesystem metadata only. Name/size matches do not prove identical contents or a backup. It does not delete files or produce executable cleanup scripts. USB pairing and bound-media rescan remain disabled; ordinary metadata scanning is supported.

Windows x64 is the product release scope. This installer has no Authenticode signature. macOS/Linux product releases remain separate; portable compile/tests continue. Windows 10 coverage is owner-confirmed historical coverage, not a new physical exact-1.1 PASS.

CTF and exported metadata acceptance is limited to the tested supported layouts. Original user catalogs remain read-only; edits/exports use separate copies and new output names. No personal catalogs or proprietary license files are distributed.

The published v1.0.0 tag/assets remain unchanged. Final release evidence records the exact source, CI run, installer and installed binary hashes. Version preparation alone is not a release or an installed GUI PASS.
