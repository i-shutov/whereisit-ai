# WhereIsIt AI 1.1.1 — Windows x64 candidate (unsigned)

This hotfix candidate addresses the slow initial opening of large CTF catalogs
reported after 1.1.0. `stable_ready=false`: installed-candidate acceptance and
publication are separate final steps. Published tags/assets remain immutable.

## Changes

- Open an immutable CTF metadata snapshot without waiting for a complete SQLite
  import or search-index build. SQLite remains available for native catalogs
  and user state; editing that requires native import remains explicit.
- Browse disks, folders and files with recorded disk/path context, parent-folder
  reveal and Back. Search pages use catalog order without a global name sort.
- Avoid repeated whole-source reads on eligible protected Windows sources;
  retain complete verification when that protection is unavailable.
- Reuse bounded, query-local ancestor matches and process longer scans in up to
  four workers. Cancellation remains available; no content indexing is added.
- Run read-only archive analytics directly on the snapshot and fix existing
  description/tag highlight query failures.

## Evidence and remaining acceptance

At code checkpoint `24d7e77`, two independent 30-sample series for each of ten
classes passed the 150 ms p95 target on 3,046,133 records: worst p95 122.112 ms,
ordinary text about 29 ms. Opening through first search was 1.273 / 1.217 seconds.
The cache was uncontrolled and these are service measurements on a four-logical-
CPU Windows 11 host, not guarantees for every query or other hardware. Peak
opening memory remains about 863 MiB working set. See the
[sanitized report](../qa/CTF_TEXT_SCAN_20261126.md) and
[PR #100 GUI validation](https://github.com/i-shutov/whereisit-ai/pull/100).

The local standard candidate passed installed upgrade from 1.1.0, restart,
uninstall/reinstall and external-data preservation. The exact hosted installer
at `3cf2d36` also passed direct full-CTF opening, paging and restart in the GUI;
installed binaries matched its provenance. An edited copy exported by the local
installed CLI opened in original WhereIsIt with its Unicode description visible.
See the [installed candidate report](../qa/WINDOWS_1_1_1_INSTALLED_CANDIDATE_20261126.md)
for the exact evidence and remaining gates. Final readiness/main artifacts are
not certified retroactively. Historical 1.1.0 evidence remains separate.

Windows x64 is the product scope. The installer is unsigned; macOS/Linux
product releases are deferred while portable compile/tests continue. Windows
10 coverage is historical owner-confirmed coverage, not an exact 1.1.1 PASS.
USB pairing and bound-media rescan remain disabled; ordinary metadata scanning
is supported. Original CTFs remain read-only and edits/exports use new copies.
No personal catalogs, paths, source hashes, proprietary licenses or screenshots
are included in this note or package.
