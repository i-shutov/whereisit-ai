# WhereIsIt AI 1.0.0 — Windows x64

Native offline Rust/egui disk catalogs for Windows. This release ships Windows x64 only. macOS/Linux releases are deferred; the core remains portable and cross-platform compile/tests continue.

## Included

- Compact metadata-only disk catalogs; Unicode and Boolean/scoped indexed search; categories and notes; folder navigation; offline metadata candidate review.
- Metadata scanning with progress, cancellation and rollback. Scanning does not execute files or read/hash media contents by default.
- Supported uncompressed Catalog 3.00 CTF import, read-only linking, guarded description edits on derivative copies, and export to new files. Edited output was independently accepted by original WhereIsIt 2014 build 220. Unsupported structures are refused; arbitrary compressed/encrypted CTF is not claimed.
- CSV, JSON and Parquet exports of complete result scopes with overwrite protection.
- Standard Windows installer, executable hash verification, and external SQLite preservation across upgrade/uninstall.

## Scope and limitations

**The Windows installer is unsigned, explicitly approved by the owner. Windows may show an unknown-publisher warning.** It is not Authenticode signed. No Apple notarization or other-platform package is claimed.

USB physical pairing and bound-device rescan are disabled in 1.0. Ordinary directory/disk metadata scanning remains available. Tabs/workspaces, sunburst/archive slices and local analyzer are deferred. Metadata matches do not prove byte equality or backups; no file deletion or cleanup export is provided.

Windows 11 installed GUI and real-data acceptance is recorded per candidate. Windows 10 was tested jointly with the owner earlier; its former test machine was removed and the owner plans later personal testing. This is not a new exact-1.0 Windows 10 claim.

Warm CLI search on the full 3,046,133-entry catalog passed 150 ms p95 without concurrent UI automation. A separate concurrent GUI-automation workload exceeded that target; concurrent-load and cold-cache performance are not certified. Source/run-bound results are recorded in acceptance metadata.

Private catalogs, private paths/source-file digests, private software licenses and raw screenshots are not release assets. Public project/dependency license notices are included.
