# Проверка готовой базы Windows CLI

Выпускной Windows x64 `atlas.exe` открыл SQLite-базу, созданную Linux-сборкой Atlas Catalog на реальном исходном каталоге. Проверка выполнена в Wine 9.0 (Ubuntu `9.0~repack-4build3`) на Linux, с целью `x86_64-pc-windows-gnu`. SHA-256 проверенного исполняемого файла: `ce0ca8528f0fcabf5946ff2b653ebac759b590eeab86df2419072ba2cd03f2a8`.

Выполнены только запросы статистики и поиска; имена и пути файлов в этом отчёте не приводятся:

| Проверка | Результат |
|---|---:|
| Томов | 44 |
| Записей | 3 046 027 |
| Первая страница `search_fast` | 250 записей; есть следующая страница |
| Точное число результатов того же запроса | 13 562 |
| Размер запрошенной страницы точного поиска | 1 запись |

Выражение: `(ext:mkv OR ext:mp4 OR ext:avi) AND size:>1GiB AND NOT name:sample`. Три последовательных запроса в одном процессе, включая запуск Wine, заняли 2,46 секунды в данном окружении; это разовая проверка совместимости, а не систематический бенчмарк.

Использован существующий изолированный Wine-prefix. Проверка подтверждает чтение базы и выполнение этих команд Windows-бинарником в Wine. Она не подтверждает работу на настоящей Windows, производительность на другом оборудовании или совместимость CTF с оригинальным приложением.
